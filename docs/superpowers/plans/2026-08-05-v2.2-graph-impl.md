# v2.2 Agent Graph 重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 v2.1 的 3 节点（agent / tools / reflect）+ 单计数器（`iterations`）重构为 v2.2 的 4 节点（iter / tools / synth / reflect）+ 3 独立计数器（`iter_count` / `synth_count` / `reflection_count`），消除 v2.1 的 3 个 bug（节点层双角色 / counter 混叠 / 工具超时死循环）。

**Architecture:** 节点层职责分离 —— iter 纯决策不写答案 / synth 单一节点处理首次+重写（按 `last_critique` 切换 prompt）/ reflect 输出 `{is_sufficient, critique, next_action}` JSON 由 Pydantic 解析。Counter 层分离 —— 3 个独立 reducer，各管自己的节点。工具层 —— `StatusToolNode(ToolNode)` 捕获 success/empty/timeout/error 写 `state["tool_status"]` 字典，避免反思误判 `re_iterate` 死循环。配置层 —— `MAX_ITER/MAX_SYNTH/MAX_REFL` 移到 `configs/agent_config.yaml` 由 `agent/constants.py` 加载。

**Tech Stack:** Python 3.11+、LangGraph (`StateGraph` / `ToolNode`)、LangChain (`bind_tools` / `with_structured_output`)、Pydantic（`ReflectOutput`）、PyYAML、pytest。所有节点统一用 `MiniMax-M3` LLM（30s 超时）。

`agent/state.py`:

```python
"""RAGMI Agent State —— LangGraph 状态契约 (v2.2)。

6 字段 schema：
- messages: 消息历史（add_messages reducer）
- iter_count: iter 节点计数器（_inc_iter reducer）
- synth_count: synth 节点计数器（_inc_synth reducer）
- reflection_count: reflect 节点计数器（_inc_refl reducer）
- tool_status: 多工具状态字典（_merge_tool_status reducer）
- last_critique: reflect 节点输出的反馈（synth 重写模式读）

替代 v2.1 的 iterations + last_reflection_pass。
"""
from typing import Annotated, TypedDict

from langchain_core.messages import BaseMessage
from langgraph.graph.message import add_messages

# ===== Reducer =====

def _inc_iter(old: int, new: int) -> int:
    """iter_count 字段 reducer：节点返回增量，框架累加。"""
    return (old or 0) + (new or 0)


def _inc_synth(old: int, new: int) -> int:
    """synth_count 字段 reducer。"""
    return (old or 0) + (new or 0)


def _inc_refl(old: int, new: int) -> int:
    """reflection_count 字段 reducer。"""
    return (old or 0) + (new or 0)


def _merge_tool_status(old: dict, new: dict) -> dict:
    """tool_status 字段 reducer：合并而非覆盖（多工具串行调用时）。"""
    return {**(old or {}), **(new or {})}


# ===== State Schema =====

class AgentState(TypedDict, total=False):
    """v2.2 Agent 运行时状态。

    字段说明
    --------
    messages : list[BaseMessage]
        消息历史（add_messages reducer）。
    iter_count : int
        iter 节点调用次数。reflect 触发 rewrite/re_iterate 时重置为 0。
    synth_count : int
        synth 节点调用次数。reflect 触发时重置为 0。
    reflection_count : int
        reflect 节点调用次数。永不重置（绝对上限）。
    tool_status : dict[str, str]
        多工具状态字典（rag_search: success / calculator: timeout ...）。
    last_critique : str
        reflect 节点最新输出的 critique；synth 重写模式时读取。
    """
    messages: Annotated[list[BaseMessage], add_messages]
    iter_count: Annotated[int, _inc_iter]
    synth_count: Annotated[int, _inc_synth]
    reflection_count: Annotated[int, _inc_refl]
    tool_status: Annotated[dict[str, str], _merge_tool_status]
    last_critique: str


def initial_state(question: str) -> AgentState:
    """构造 Agent 初始 state。"""
    return {
        "messages": [],
        "iter_count": 0,
        "synth_count": 0,
        "reflection_count": 0,
        "tool_status": {},
        "last_critique": "",
    }
```

"""agent/nodes/status_tool_node.py —— StatusToolNode (v2.2)。

包装 LangGraph ToolNode，捕获工具执行状态写入 state["tool_status"] 字典。
4 种 status 值：
- success: 工具返回非空内容
- empty: 工具返回空字符串（无超时）
- timeout: 工具抛 TimeoutError
- error: 工具抛其他异常

兜底：timeout/error 时仍写 ToolMessage（避免 graph 卡住）。
"""
from langchain_core.messages import ToolMessage
from langgraph.prebuilt import ToolNode

from agent.state import AgentState


class StatusToolNode(ToolNode):
    """包装 LangGraph ToolNode，捕获异常写 tool_status 字典。"""

    def __init__(self, tools: list):
        super().__init__(tools)

    def __call__(self, state: AgentState) -> dict:
        # 取最后一个 AIMessage 的 tool_calls
        last_msg = state["messages"][-1]
        if not (hasattr(last_msg, "tool_calls") and last_msg.tool_calls):
            return {}  # 没有 tool_calls 不应到这（兜底）

        tool_call = last_msg.tool_calls[0]
        tool_name = tool_call["name"]
        tool_call_id = tool_call["id"]

        try:
            result = super().__call__(state)
            # ToolNode 返回 {"messages": [ToolMessage, ...]}
            tool_msgs = result.get("messages", [])
            has_content = any(getattr(m, "content", "") for m in tool_msgs)
            status = "success" if has_content else "empty"
            return {
                **result,
                "tool_status": {tool_name: status},
            }
        except TimeoutError:
            # 兜底：写 ToolMessage 占位（避免 graph 卡在 tool_calls 未应答）
            return {
                "messages": [ToolMessage(
                    content="查询超时",
                    tool_call_id=tool_call_id,
                    name=tool_name,
                )],
                "tool_status": {tool_name: "timeout"},
            }
        except Exception:
            return {
                "messages": [ToolMessage(
                    content="工具异常",
                    tool_call_id=tool_call_id,
                    name=tool_name,
                )],
                "tool_status": {tool_name: "error"},
            }
```

"""agent/nodes/should_continue.py —— 条件边路由函数 (v2.2)。

v2.2 包含 2 个条件边：
- should_continue: iter → {tools, synth}
- after_reflect: reflect → {END, synth, iter}
"""
from agent.constants import MAX_ITER


def should_continue(state: dict) -> str:
    """iter 节点之后的条件路由。

    输入：state dict (含 messages, iter_count)
    输出："tools" / "synth"
    """
    # 兜底 1：迭代超限强制走 synth（让 reflect 接管，避免再调工具）
    if state.get("iter_count", 0) >= MAX_ITER:
        return "synth"

    last_message = state["messages"][-1]

    # 有工具调用 → tools
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"

    # 默认（含 LLM 乱码 / READY 信号） → synth
    return "synth"


def after_reflect(state: dict) -> str:
    """reflect 节点之后的条件路由。

    输入：state dict (含 next_action)
    输出："__end__" / "synth" / "iter"
    """
    action = state.get("next_action", "end")
    if action == "end":
        return "__end__"
    if action == "rewrite":
        return "synth"
    if action == "re_iterate":
        return "iter"
    # 兜底：未知 action 走 END
    return "__end__"

"""agent/nodes/synth_node.py —— v2.2 综合节点。

单一节点处理"首次写答案"和"重写答案"两种模式：
- 首次：state["last_critique"] 为空 → 基于素材写答案
- 重写：state["last_critique"] 非空 → 基于素材 + critique 改写

不调工具（v2.1 节点双角色 bug 修复点）。
"""
from langchain_core.messages import AIMessage, HumanMessage, SystemMessage

from agent.constants import MAX_SYNTH
from agent.prompts.synth_prompt import SYNTH_PROMPT
from agent.state import AgentState


def _get_llm():
    """懒加载 LLM（不挂 bind_tools，30s 超时）。"""
    from utils.models.model_setting import LLMmodel

    llm_instance = LLMmodel.create_minimax("MiniMax-M3")
    return llm_instance.chat.with_config({"timeout": 30})


def _format_tool_status(tool_status: dict) -> str:
    """把 tool_status dict 格式化为可读字符串。"""
    if not tool_status:
        return "（无工具调用）"
    lines = [f"- {name}: {status}" for name, status in tool_status.items()]
    return "\n".join(lines)


def synth_node(state: AgentState, llm=None) -> dict:
    """综合节点：写最终答案。

    Args:
        state: AgentState
        llm: 可选注入的 LLM（测试用）；None 时懒加载真实 LLM

    Returns:
        dict 含 "messages" (单条 AIMessage) 和 "synth_count" 增量 + "last_critique" 透传
    """
    synth_count = state.get("synth_count") or 0

    # 边界：综合上限强制输出提示
    if synth_count >= MAX_SYNTH:
        return {
            "messages": [AIMessage(content="已达综合上限，结束")],
            "synth_count": 1,
            "last_critique": state.get("last_critique", ""),
        }

    if llm is None:
        llm = _get_llm()

    # 构造 prompt
    question = state["messages"][0].content if state["messages"] else ""
    tool_status = state.get("tool_status", {})
    last_critique = state.get("last_critique", "")

    # 提取素材：从 messages 中找最近的 ToolMessage 内容
    chunks_text = ""
    for msg in reversed(state["messages"]):
        # ToolMessage 是 LangChain 标准类，有 content 属性
        if msg.__class__.__name__ == "ToolMessage" and getattr(msg, "content", ""):
            chunks_text = msg.content
            break

    prompt_messages = [
        SystemMessage(content=SYNTH_PROMPT),
        HumanMessage(content=(
            f"【用户问题】\n{question}\n\n"
            f"【可用素材】（如果有）\n{chunks_text}\n\n"
            f"【工具状态】\n{_format_tool_status(tool_status)}\n\n"
            f"【反思反馈】（如果有——重写模式才有）\n{last_critique}\n"
        )),
    ]

    # LLM 调用（带异常兜底）
    try:
        response = llm.invoke(prompt_messages)
    except Exception as e:
        response = AIMessage(content=f"综合答案生成失败：{type(e).__name__}")

    return {
        "messages": [response],
        "synth_count": 1,
        "last_critique": last_critique,  # 透传（reflect 下次会更新）
    }

"""agent/nodes/reflect_node.py —— v2.2 反思节点。

v2.2 变化（vs v2.1）：
- 用 Pydantic ReflectOutput 解析（替代正则 + JSON 三层 fallback）
- 输出 next_action 字段（end / rewrite / re_iterate）
- 失败 fallback：next_action = rewrite（reflection_count 上限兜底防死循环）
- reflection_count >= MAX_REFL → 强制 next_action = end
- rewrite / re_iterate 时重置 iter_count + synth_count = 0
"""
from typing import Literal

from langchain_core.messages import AIMessage, HumanMessage, SystemMessage
from pydantic import BaseModel, Field

from agent.constants import MAX_REFL
from agent.prompts.reflect_prompt import REFLECT_PROMPT
from agent.state import AgentState


class ReflectOutput(BaseModel):
    """Structured output for reflect node。

    Fields:
        is_sufficient: 答案是否通过评审。
        critique: 若 insufficient 写修改方向；否则留空。
        next_action: end (通过) / rewrite (synth 重写) / re_iterate (回 iter)。
    """
    is_sufficient: bool
    critique: str = ""
    next_action: Literal["end", "rewrite", "re_iterate"]


def _get_llm():
    """懒加载反思 LLM（with_structured_output, 30s 超时）。"""
    from utils.models.model_setting import LLMmodel

    llm_instance = LLMmodel.create_minimax("MiniMax-M3")
    return (
        llm_instance.chat
        .with_structured_output(ReflectOutput)
        .with_config({"timeout": 30})
    )


def _extract_latest_answer(messages: list) -> str:
    """从 messages 中提取最后一条 AIMessage 的内容。"""
    for msg in reversed(messages):
        if isinstance(msg, AIMessage):
            return msg.content or ""
    return ""


def reflect_node(state: AgentState, llm=None) -> dict:
    """反思节点：评答案质量，决定 next_action。

    Args:
        state: AgentState
        llm: 可选注入的 LLM（测试用）；None 时懒加载真实 LLM

    Returns:
        dict 含 "reflection_count" 增量、"next_action"、"last_critique"，
        以及（rewrite/re_iterate 时）"iter_count" 和 "synth_count" 重置。
    """
    reflection_count = state.get("reflection_count") or 0

    # 边界：反思超限强制 end（兜底防死循环）
    if reflection_count >= MAX_REFL:
        return {
            "reflection_count": 1,
            "next_action": "end",
            "last_critique": state.get("last_critique", ""),
        }

    if llm is None:
        llm = _get_llm()

    # 构造 prompt
    question = state["messages"][0].content if state["messages"] else ""
    latest_answer = _extract_latest_answer(state["messages"])
    tool_status = state.get("tool_status", {})

    prompt_messages = [
        SystemMessage(content=REFLECT_PROMPT),
        HumanMessage(content=(
            f"【用户问题】\n{question}\n\n"
            f"【本次答案】\n{latest_answer}\n\n"
            f"【工具状态】\n{tool_status}\n\n"
            f"【历史反思】（本次会话内）\n{state.get('last_critique', '')}\n"
        )),
    ]

    # LLM 调用 + Pydantic 解析（带异常兜底）
    try:
        parsed = llm.invoke(prompt_messages)
        # Pydantic 模型 → dict
        action = parsed.next_action
        critique = parsed.critique
    except Exception:
        # LLM 失败 / Pydantic 解析失败 → 兜底 rewrite（reflection_count 上限兜底防死循环）
        action = "rewrite"
        critique = "反思解析失败"

    result = {
        "reflection_count": 1,
        "next_action": action,
        "last_critique": critique,
    }

    # rewrite / re_iterate 时重置 iter_count + synth_count
    if action != "end":
        result["iter_count"] = 0
        result["synth_count"] = 0

    return result

"""agent/graph.py —— LangGraph 图装配 (v2.2)。

4 节点：iter / tools / synth / reflect
边：
  START → iter (无条件)
  iter → {tools, synth} (should_continue)
  tools → iter (无条件)
  synth → reflect (无条件)
  reflect → {END, synth, iter} (after_reflect)
"""
from langgraph.graph import END, StateGraph

from agent.nodes.iter_node import iter_node
from agent.nodes.reflect_node import reflect_node
from agent.nodes.should_continue import after_reflect, should_continue
from agent.nodes.status_tool_node import StatusToolNode
from agent.nodes.synth_node import synth_node
from agent.state import AgentState
from agent.tools import ALL_TOOLS


def build_graph():
    """构造 + 编译 LangGraph 图，返回可 invoke 的对象。"""
    tool_node = StatusToolNode(ALL_TOOLS)

    workflow = StateGraph(AgentState)

    # 4 节点
    workflow.add_node("iter", iter_node)
    workflow.add_node("tools", tool_node)
    workflow.add_node("synth", synth_node)
    workflow.add_node("reflect", reflect_node)

    # 入口
    workflow.set_entry_point("iter")

    # 第一个条件边：iter → {tools, synth}
    workflow.add_conditional_edges(
        "iter",
        should_continue,
        {
            "tools": "tools",
            "synth": "synth",
        },
    )

    # tools → iter（ReAct 循环核心）
    workflow.add_edge("tools", "iter")

    # synth → reflect（无条件）
    workflow.add_edge("synth", "reflect")

    # 第二个条件边：reflect → {END, synth, iter}
    workflow.add_conditional_edges(
        "reflect",
        after_reflect,
        {
            "end": END,
            "rewrite": "synth",
            "re_iterate": "iter",
        },
    )

    return workflow.compile()
```

## Task 17: 更新 `agent/runtime.py` 适配 debug 模式

"""agent/runtime.py —— 对外统一调用入口 (v2.2)。

v2.2 变化：
- debug 模式返回 6 字段：answer / iter_count / synth_count / reflection_count / tool_called / last_action
- last_action 来自 state.next_action（reflect 节点的输出）
- 删除 score 字段（v2.1 由 last_reflection_pass 推导，v2.2 用 last_action 替代）
"""
from langchain_core.messages import AIMessage

from agent.graph import build_graph
from utils.logging import get_logger

logger = get_logger(__name__)


_graph = None


def _get_graph():
    """懒加载 graph 单例。"""
    global _graph
    if _graph is None:
        _graph = build_graph()
    return _graph


def _extract_answer(messages: list) -> str:
    """从 messages 中提取最后一条 AIMessage 的内容作为答案。"""
    for msg in reversed(messages):
        if isinstance(msg, AIMessage):
            return msg.content or ""
    return ""


def _error_response(debug: bool):
    msg = "抱歉，agent 调用异常，请稍后重试。"
    if not debug:
        return msg
    return {
        "answer": msg,
        "iter_count": 0,
        "synth_count": 0,
        "reflection_count": 0,
        "tool_called": False,
        "last_action": "error",
    }


def ask(
    question: str,
    session_id: str | None = None,
    debug: bool = False,
) -> str | dict:
    """统一对话入口。

    输入：
    - question: 用户问题
    - session_id: 会话 ID（暂未启用多轮持久化）
    - debug: 是否返回 metadata dict（默认 False 返回 str）

    输出：
    - debug=False: 纯文本答案
    - debug=True: {"answer", "iter_count", "synth_count", "reflection_count", "tool_called", "last_action"}
    """
    graph = _get_graph()
    config = {"configurable": {"thread_id": session_id}} if session_id else None

    logger.info(f"ask() entry: query={question[:50]}... session={session_id}")

    try:
        from langchain_core.messages import HumanMessage
        result = graph.invoke(
            {"messages": [HumanMessage(question)]},
            config=config,
        )
    except Exception as e:
        logger.exception(f"ask() failed: {type(e).__name__}: {e}")
        return _error_response(debug)

    answer = _extract_answer(result["messages"])

    if not debug:
        return answer

    # debug 模式：返回 6 字段 metadata
    return {
        "answer": answer,
        "iter_count": result.get("iter_count", 0),
        "synth_count": result.get("synth_count", 0),
        "reflection_count": result.get("reflection_count", 0),
        "tool_called": bool(result.get("tool_status", {})),
        "last_action": result.get("next_action", "end"),
    }
```

找到 `CLAUDE.md` 的 "LangGraph Agent" 小节（行号见 git blame），替换为：

```markdown
## LangGraph Agent (v2.2)

The Agent is a single-Agent, multi-tool ReAct-style graph with an LLM-as-judge reflection step. v2.2 替换 v2.1 解决 3 个 bug：节点层双角色 / counter 混叠 / 工具超时死循环。

```text
START → iter
          ├─ tool_calls present → tools → iter (loop)
          └─ no tool call (incl. "READY" / 乱码 / iter_count ≥ MAX_ITER) → synth

synth
  ├─ synth_count < MAX_SYNTH → 写答案 → reflect
  └─ synth_count ≥ MAX_SYNTH → 强制 END

reflect
  ├─ end → END
  ├─ rewrite → synth（synth_count 已重置）
  ├─ re_iterate → iter（iter_count 已重置）
  └─ reflection_count ≥ MAX_REFL → 强制 end（兜底防死循环）
```

### 4 节点 vs v2.1 3 节点

v2.1 节点：`agent`（决策+综合双角色）/ `tools` / `reflect`

v2.2 节点：`iter`（纯决策，不写答案）/ `tools` / `synth`（综合）/ `reflect`

分离原因：v2.1 agent_node 同时承担"决定要不要调工具"和"写最终答案"两种 LLM 模式，互相干扰。v2.2 拆为 2 个节点 + `iter` 用 `READY` 信号交接。

### 3 counter vs v2.1 单 counter

v2.1：`iterations`（单计数器，混叠 agent_node 决策+综合次数，导致反思触发条件短路）

v2.2：`iter_count` / `synth_count` / `reflection_count` 三个独立计数器，各管自己的节点：

- `iter_count` — iter 节点调用次数，上限 `MAX_ITER=3`，reflect rewrite/re_iterate 时重置
- `synth_count` — synth 节点调用次数，上限 `MAX_SYNTH=2`，reflect 时重置
- `reflection_count` — reflect 节点调用次数，上限 `MAX_REFL=3`，**永不重置**（绝对上限，防死循环）

### 工具状态（防死循环 bug）

`StatusToolNode(ToolNode)` 包装 LangGraph ToolNode，写 `state["tool_status"]` 字典：

| 值 | 触发条件 |
|---|---|
| `success` | 工具返回非空内容 |
| `empty` | 工具返回空字符串 |
| `timeout` | 工具抛 TimeoutError |
| `error` | 工具抛其他异常 |

reflect prompt 硬约束：工具 timeout/error 时不应判 `re_iterate`（否则 `iter → tools(超时) → iter` 死循环）。即便 LLM 误判，`MAX_REFL=3` 兜底强制 end。

### 配置

`configs/agent_config.yaml` 定义 `MAX_ITER` / `MAX_SYNTH` / `MAX_REFL`。`agent/constants.py` 加载并导出，启动时 assert 校验。

### 工具清单

4 个：`rag_search`（已有）/ `calculator` / `weather` / `web_search`（3 个占位实现）。

### 节点细节

- `agent/nodes/iter_node.py`：`bind_tools(ALL_TOOLS)`，prompt 强制"不调工具时输出 READY"，含 try/except + `iter_count >= MAX_ITER` 边界检查
- `agent/nodes/synth_node.py`：不挂 `bind_tools`，按 `state["last_critique"]` 是否空切换 prompt 模式（首次 vs 重写），含 try/except + `synth_count >= MAX_SYNTH` 边界检查
- `agent/nodes/reflect_node.py`：用 `with_structured_output(ReflectOutput)`，Pydantic 解析；失败 fallback `next_action=rewrite`；超 `MAX_REFL` 强制 end；rewrite/re_iterate 时重置 iter/synth count
- `agent/nodes/status_tool_node.py`：包装 `ToolNode`，4 种 status 值 + ToolMessage 兜底（避免 graph 卡在 tool_calls 未应答）
- `agent/nodes/should_continue.py`：含 2 个条件边函数（`should_continue` + `after_reflect`）

    result = subprocess.run(
        ["python", "test/run_agent_eval.py", "--mock"],
        capture_output=True,
        text=True,
        env={**os.environ, "PYTHONIOENCODING": "utf-8", "PYTHONPATH": "."},

    assert result.returncode == 0, f"mock eval failed: {result.stderr[:500]}"
    # 输出文件 test/agent_eval_results.json 应被生成
    assert Path("test/agent_eval_results.json").exists()


@pytest.mark.slow
def test_eval_real_mode_accuracy_above_92():
    """真实 LLM 评估：准确率 ≥ 92%。"""
    import subprocess

    result = subprocess.run(
        ["python", "test/run_agent_eval.py"],
        capture_output=True,
        text=True,
        env={**os.environ, "PYTHONIOENCODING": "utf-8", "PYTHONPATH": "."},

    # 读评估结果
    import json
    with open("test/agent_eval_results.json", encoding="utf-8") as f:
        results = json.load(f)

    accuracy = results.get("accuracy", 0)
    assert accuracy >= 0.92, f"accuracy {accuracy} 低于 v2.1 baseline 92%"
