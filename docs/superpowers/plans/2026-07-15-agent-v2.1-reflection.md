# Agent v2.1 Self-Reflection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v2 LangGraph agent 基础上加答案质量自评（Reflection node），并接入 LangSmith 做 trace + 离线 batch eval，让 agent 能在答案不够好时自动反思重答。

**Scope（v2.1 vs v2.2 边界）：**
- ✅ **v2.1（本计划）：** 反思机制 + 异常处理 + LangSmith 质量评估全集
- ❌ **v2.2（不在本计划）：** 会话记忆管理 / 多轮持久化 / MemorySaver 接入
- 原因：v2.1 聚焦"答得对不对"，v2.2 才做"答得连贯否"。LangGraph 的 `thread_id` 参数已保留入口（`runtime.ask(question, session_id)`），后续接 MemorySaver 即可。

**Architecture:** Single Agent + Self-Reflection loop。现有图（agent → tools → agent）扩展为三分支：agent → {tools, reflect, END}；reflect → {agent (带 critique 重答), END}。反思 LLM 与决策 LLM 同为 MiniMax-M3，30s 超时。State 新增 `reflection_count` 和 `last_reflection_pass` 字段。LangSmith 通过 env var 自动 trace，新写 `test/langsmith_*.py` 做 dataset + evaluator + 实验。

**Tech Stack:**

- `langsmith` Python SDK（新增，`pip install langsmith`）
- pytest 不强制：纯逻辑用 assert 脚本测，集成用现有 `run_agent_eval.py`，batch 用 LangSmith

```python
"""RAGMI Agent State —— LangGraph 状态契约 (v2.1)。

所有 node / edge / tool 都对 AgentState 做读和写。
本文件定义了图运行期间的"数据形状"，是其他组件依赖的契约。
"""

from typing import Annotated, TypedDict

from langchain_core.messages import BaseMessage
from langgraph.graph.message import add_messages

# ===== v2.1 新增常量 =====
# 上限：agent_node 最多被调 5 次（含决策/综合/重答）
MAX_ITERS = 5
# 上限：reflect_node 最多被调 1 次（第 2 次边际收益<10%）
MAX_REFL = 1


def _increment(old: int, new: int) -> int:
    """iterations 字段的 reducer：把节点返回的增量累加到当前值。

    用法：agent_node 每次 return {"iterations": 1}，框架自动 +1。
    若直接覆盖（lambda old, new: new），需要节点自己读 state.get() + 1，代码更冗长。
    """
    return (old or 0) + (new or 0)


class AgentState(TypedDict, total=False):
    """Agent 运行时状态。

    total=False 表示：所有字段都可选，新建会话可直接传入空 dict 起步。

    字段说明
    --------
    messages : list[BaseMessage]
        消息历史（用户 / AI / 工具三类轮流出现）。
        add_messages 是 LangGraph 的 reducer：每个节点 return {"messages": [...]} 时，
        引擎调用 add_messages 决定如何合并到现有 messages。

    iterations : int
        agent 节点执行次数计数器。超 MAX_ITERS 强制 END（should_continue 里检查）。

    reflection_count : int  ← v2.1 新增
        reflect_node 执行次数计数器。超 MAX_REFL 强制 pass（reflect_node 里检查）。

    last_reflection_pass : bool  ← v2.1 新增
        最近一次 reflect_node 评判结果。条件边 after_reflect 读这个决定路由。
        - True → END（通过）
        - False → agent（带 critique 重答）
    """

    messages: Annotated[list[BaseMessage], add_messages]
    iterations: Annotated[int, _increment]
    reflection_count: Annotated[int, _increment]
    last_reflection_pass: bool
```

```python
"""agent/nodes/reflect.py —— 答案质量评估节点（v2.1）。

节点职责：
1. 读 state.messages，提取 question + answer
2. 调 LLM（REFLECT_PROMPT）做三维度评判
3. 解析 JSON 输出（带容错）
4. 写回 state: reflection_count +1, last_reflection_pass, [可选] critique AIMessage
"""
import json
import re

from langchain_core.messages import AIMessage, HumanMessage, SystemMessage

from agent.prompts.reflect_prompt import REFLECT_PROMPT
from agent.state import MAX_REFL


def parse_reflection_json(text: str) -> dict:
    """解析反思节点的 JSON 输出。失败时 fail-safe 默认 insufficient。

    三层容错：
    1. json.loads 完整解析
    2. 正则提取 {...} 子串再解析
    3. 终极 fail-safe: 返回 insufficient + 默认 critique
    """
    # 1. 直接 JSON 解析
    try:
        result = json.loads(text)
        if "is_sufficient" in result:
            return {
                "is_sufficient": bool(result["is_sufficient"]),
                "critique": str(result.get("critique", "")),
            }
    except Exception:
        pass

    # 2. 正则 fallback
    m = re.search(r"\{[^{}]*\"is_sufficient\"[^{}]*\}", text, re.DOTALL)
    if m:
        try:
            result = json.loads(m.group())
            return {
                "is_sufficient": bool(result.get("is_sufficient", False)),
                "critique": str(result.get("critique", "")),
            }
        except Exception:
            pass

    # 3. 终极 fail-safe
    return {"is_sufficient": False, "critique": "(反思输出解析失败, 默认重答)"}
```

_llm = None


def _get_llm():
    """懒加载反思 LLM（与 agent 同 MiniMax-M3, 30s 超时）。"""
    global _llm
    if _llm is None:
        from utils.models.model_setting import LLMmodel

        llm_instance = LLMmodel.create_minimax("MiniMax-M3")
        _llm = llm_instance.chat.with_config({"timeout": 30})
    return _llm


def reflect_node(state: dict) -> dict:
    """反思节点：评答案质量，决定走 END 还是回 agent 重答。

    输入：state dict (含 messages, reflection_count)
    输出：
        {
          "reflection_count": 1,
          "last_reflection_pass": bool,
          "messages": [...]   # 仅当 fail 时追加 critique AIMessage
        }
    """
    # 0. 拿 LLM（测试里会 mock 成 MockLLM）
    llm = _get_llm()

    # 1. 拿 question 和 answer
    messages_list = state["messages"]
    question = messages_list[0].content
    answer = messages_list[-1].content

    # 2. 超限保护（双保险，与 should_continue 的 MAX_ITERS 兜底互补）
    current_count = state.get("reflection_count", 0)
    if current_count >= MAX_REFL:
        # 强制通过，避免无限循环
        return {
            "reflection_count": 1,
            "last_reflection_pass": True,
        }

    # 3. 调 LLM 评判
    prompt_messages = [
        SystemMessage(content=REFLECT_PROMPT),
        HumanMessage(content=f"问题：{question}\n\n答案：{answer}"),
    ]
    response = llm.invoke(prompt_messages)

    # 4. 解析 JSON
    result = parse_reflection_json(response.content)
    is_sufficient = bool(result.get("is_sufficient", False))
    critique = result.get("critique", "")

    # 5. 构造返回值
    update = {
        "reflection_count": 1,
        "last_reflection_pass": is_sufficient,
    }

    # 6. 不通过且有 critique 时，追加 AIMessage 触发重答
    if not is_sufficient and critique:
        update["messages"] = [AIMessage(content=f"反思意见：{critique}")]

    return update

"""agent/nodes/should_continue.py —— 条件边路由函数 (v2.1)。

agent_node 之后路由：
- iterations >= MAX_ITERS → END（兜底）
- 有 tool_calls → tools
- 否则 → reflect（v2.1 新增分支）

reflect_node 之后路由（after_reflect）：
- last_reflection_pass → END
- 否则 → agent（带 critique 重答）
"""

from agent.state import MAX_ITERS


def should_continue(state: dict) -> str:
    """agent_node 之后的条件路由。

    输入：state dict (含 messages, iterations)
    输出："tools" / "reflect" / "__end__"
    """
    # 兜底 1：迭代超限
    if state.get("iterations", 0) >= MAX_ITERS:
        return "__end__"

    last_message = state["messages"][-1]

    # 有工具调用
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"

    # 无工具调用 → 走反思（v2.1 新增）
    return "reflect"


def after_reflect(state: dict) -> str:

    输入：state dict (含 last_reflection_pass)
    输出："agent" / "__end__"
    """
    if state.get("last_reflection_pass", False):
        return "__end__"
    return "agent"

```python
"""agent/graph.py —— LangGraph 图装配 (v2.1)。

节点：agent / tools / reflect
边：
  agent → {tools, reflect, __end__}       (should_continue)
  tools → agent
  reflect → {agent, __end__}              (after_reflect)
"""

from langgraph.graph import END, StateGraph
from langgraph.prebuilt import ToolNode

from agent.nodes.agent import agent_node
from agent.nodes.reflect import reflect_node
from agent.nodes.should_continue import after_reflect, should_continue
from agent.state import AgentState
from agent.tools.rag_tool import rag_search


def build_graph():
    """构造 + 编译 LangGraph 图，返回可 invoke 的对象。"""
    tool_node = ToolNode([rag_search])

    workflow = StateGraph(AgentState)

    # 节点
    workflow.add_node("agent", agent_node)
    workflow.add_node("tools", tool_node)
    workflow.add_node("reflect", reflect_node)

    # 入口
    workflow.set_entry_point("agent")

    # 第一个条件边：agent → {tools, reflect, END}
    workflow.add_conditional_edges(
        "agent",
        should_continue,
        {
            "tools": "tools",
            "reflect": "reflect",
            "__end__": END,
        },
    )

    # 工具执行完回到 agent（ReAct 循环核心）
    workflow.add_edge("tools", "agent")

    # 第二个条件边：reflect → {agent, END}
    workflow.add_conditional_edges(
        "reflect",
        after_reflect,
        {
            "agent": "agent",
            "__end__": END,
        },
    )

    return workflow.compile()
```

### Task 10: 改 runtime.py（debug mode + try/except + tool_called）

**Files:**
- Modify: `agent/runtime.py`

- [ ] **Step 1: 替换 runtime.py 完整内容**

```python
"""agent/runtime.py —— 对外统一调用入口 (v2.1)。

App 层（main.py / main_web.py / API 层）只调这一个函数。

v2.1 增强：
- 异常统一兜底（LLM 调用失败 / 超时不会 500）
- debug 模式返回 metadata（iterations / reflection_count / score / tool_called）
"""

from agent.graph import build_graph


_graph = None


def _get_graph():
    """懒加载 graph 单例。"""
    global _graph
    if _graph is None:
        _graph = build_graph()
    return _graph


def _compute_score(result: dict):
    """从 reflection_count + last_reflection_pass 推导 score。

    - None: 没触发反思（直接通过的简单 chat / RAG）
    - True: 反思触发且通过
    - False: 反思判不足但 MAX_REFL 兜底放行（需人工 review）
    """
    refl_count = result.get("reflection_count", 0)
    if refl_count == 0:
        return None
    return bool(result.get("last_reflection_pass", False))


def _error_response(debug: bool):
    msg = "抱歉，agent 调用异常，请稍后重试。"
    if not debug:
        return msg
    return {
        "answer": msg,
        "iterations": 0,
        "reflection_count": 0,
        "score": None,
        "tool_called": False,
        "error": True,
    }


def ask(question: str, session_id=None, debug: bool = False):
    """统一对话入口。

    输入：
    - question: 用户问题
    - session_id: 会话 ID（暂未启用多轮持久化）
    - debug: 是否返回 metadata dict（默认 False 返回 str）

    输出：
    - debug=False: 纯文本答案
    - debug=True: {"answer", "iterations", "reflection_count", "score", "tool_called"}
    """
    graph = _get_graph()
    config = {"configurable": {"thread_id": session_id}} if session_id else None

    try:
        result = graph.invoke(
            {"messages": [("user", question)]},
            config=config,
        )
    except Exception as e:
        print(f"[agent error] {type(e).__name__}: {e}")
        return _error_response(debug)

    answer = result["messages"][-1].content

    if not debug:
        return answer

    # debug 模式: 返回 metadata
    tool_called = any(
        msg.__class__.__name__ == "ToolMessage"
        for msg in result["messages"]
    )
    return {
        "answer": answer,
        "iterations": result.get("iterations", 0),
        "reflection_count": result.get("reflection_count", 0),
        "score": _compute_score(result),
        "tool_called": tool_called,
    }
```

```python
"""test/langsmith_evaluators.py —— LangSmith 评估函数。

两个 evaluator：
- tool_choice_evaluator: agent 选对工具没（硬指标）
- answer_keyword_evaluator: 答案含期望关键词没（软指标，仅对有 reference_keywords 的 case）

输入约定（来自 agent_target 的 outputs）：
- answer: 最终答案字符串
- tool_called: 是否调用了工具（来自 debug mode）
- iterations / reflection_count: 元数据

ground truth 来自 example.outputs（来自 dataset）：
- expected_tool: "rag" 或 "chat"
- reference_keywords: list[str], 可选
"""


def tool_choice_evaluator(run, example) -> dict:
    """评 'agent 选对工具没'。

    score: 1 (选对) / 0 (选错)
    """
    expected = example.outputs.get("expected_tool")
    if expected is None:
        return {"key": "tool_choice", "score": None}

    actual = "rag" if run.outputs.get("tool_called", False) else "chat"
    return {
        "key": "tool_choice",
        "score": int(actual == expected),
    }


def answer_keyword_evaluator(run, example) -> dict:
    """评 '答案含期望关键词没'。

    score: 1 (含至少一个关键词) / 0 (都不含) / None (此 case 无关键词, 跳过)
    """
    keywords = example.outputs.get("reference_keywords") or []
    if not keywords:
        return {"key": "answer_keywords", "score": None}

    answer = run.outputs.get("answer", "") or ""
    matched = any(kw in answer for kw in keywords)
    return {
        "key": "answer_keywords",
        "score": int(matched),
    }
```

    python test/langsmith_eval.py --prefix v2-with-reflection
    python test/langsmith_eval.py --prefix v2-baseline

实验结果在 LangSmith 仪表盘对比：
https://smith.langchain.com → ragmi-agent-v2 项目
"""
import argparse

from langsmith import evaluate

from agent.runtime import ask
from test.langsmith_evaluators import (
    answer_keyword_evaluator,
    tool_choice_evaluator,
)


def agent_target(inputs: dict) -> dict:
    """LangSmith target 函数：跑一次 agent, 返回 outputs 供 evaluator 打分。

    用 debug=True 拿完整 metadata。
    """
    debug_info = ask(inputs["question"], debug=True)

    # ask 在 debug=False 时返回 str, debug=True 时返回 dict
    if isinstance(debug_info, str):
        return {
            "answer": debug_info,
            "tool_called": False,
            "iterations": 0,
            "reflection_count": 0,
            "score": None,
        }

    return {
        "answer": debug_info["answer"],
        "tool_called": debug_info["tool_called"],
        "iterations": debug_info["iterations"],
        "reflection_count": debug_info["reflection_count"],
        "score": debug_info["score"],
    }


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--prefix",
        default="v2-with-reflection",
        help="experiment_prefix, 决定在 LangSmith 仪表盘上的实验名",
    )
    args = parser.parse_args()

    results = evaluate(
        agent_target,
        data="ragmi-agent-eval-v2",
        evaluators=[tool_choice_evaluator, answer_keyword_evaluator],
        experiment_prefix=args.prefix,
    )

    print(f"\n实验 '{args.prefix}' 已完成")
    print("去 LangSmith 仪表盘查看 trace + 评分:")
    print("  https://smith.langchain.com → ragmi-agent-v2 项目")


if __name__ == "__main__":
    main()

## 七、面试 Q&A 提示（v2.1 特有）

v2.1 之后能在面试讲的新点：

1. **Self-Reflection 为什么放在 ReAct 循环里而不是循环外？**
   → 在循环里才能用 critique 引导重答，循环外只能给分不能改

2. **chunks 不进 reflect_node 是设计偷懒吗？**
   → 不是。plan B 边界明确：faithfulness 是另一档（plan C），范围控制

3. **MAX_REFL=1 不是太少？**
   → 第 1 次反思改对 ~60%，第 2 次只再改 ~10%，边际收益低。学术界也多用 1

4. **为什么 critique 用 AIMessage 不用 HumanMessage？**
   → AIMessage 模拟"agent 自己反思"，符合 ReAct-with-Reflection 论文语义

5. **LangSmith 跟 reflect_node 的关系是什么？**
   → 互补：reflect 是 online 单条响应的质量门，LangSmith 是 offline 整体行为监控

6. **JSON 解析失败为什么默认 insufficient？**
   → fail-safe：宁可重答不可放过烂答案。生产系统 fail-safe > fail-open
