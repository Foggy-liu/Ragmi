**证据链**：


### 4.1 Q2 的技术细节（已对着 langgraph 1.0.5 源码逐行验证）

**根因 1 —— 包错了方法**：

```text
langgraph/prebuilt/tool_node.py:752
    super().__init__(self._func, self._afunc, ...)  →  RunnableCallable.__init__
                                                        →  self.func = self._func
langgraph/_internal/_runnable.py:329  RunnableCallable.invoke
    →  ret = self.func(*args, **kwargs)      ← 只走 _func，绕开 __call__
```

**根因 2 —— 异常默认被 re-raise**：`ToolNode` 的 `handle_tool_errors` 默认 `_default_handle_tool_errors`，
**只把 `ToolException` 转成 ToolMessage，普通异常原样抛出** → 现有代码里
`except TimeoutError` / `except Exception` 两个分支**永远触发不了**。

**两个候选修法**：

| | 方案 1：重写 `_func`（推荐） | 方案 2：重写 `invoke` |
|---|---|---|
| 写法 | `def _func(self, input, config, runtime):` | `def invoke(self, input, config=None, **kwargs):` |
| 坑 | 参数名必须叫 `config` / `runtime`，改名 → runtime 注入失效 | async 路径（`ainvoke`）不覆盖 |

### 4.2 Q5 的技术细节

**注意**：无论走哪个方向，三个节点取素材的范围都应该是**本轮全部 ToolMessage**——
